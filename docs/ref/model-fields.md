# Model field reference

Every field kind a model can have: the Rust type that selects it, the `#[field(...)]` attributes it accepts, and the
column it creates on SQLite and PostgreSQL. For how models are declared and used see [Models](../topics/db/models.md);
for relations see [Relations](../topics/db/relations.md).

## Field kinds

The kind is inferred from the Rust type of the field (the last segment of the type path, so
`chrono::DateTime<Utc>` and `DateTime<Utc>` are the same). `Option<T>` makes the column nullable. Where several kinds
share a Rust type, a flag picks one. A type the derive does not know is a compile error
(`cannot infer a model field type for ...`).

| Kind (`FieldType::`) | Rust type | Selected by | SQLite column | PostgreSQL column |
|---|---|---|---|---|
| `Auto` | integer, usually `Option<i64>` | `#[field(primary_key, auto)]` | `integer NOT NULL PRIMARY KEY AUTOINCREMENT` | `integer GENERATED BY DEFAULT AS IDENTITY` |
| `BigAuto` | integer, usually `Option<i64>` | `#[field(primary_key, big_auto)]` | `integer NOT NULL PRIMARY KEY AUTOINCREMENT` | `bigint GENERATED BY DEFAULT AS IDENTITY` |
| `SmallAuto` | | hand-built fields only | `integer ... AUTOINCREMENT` | `smallint GENERATED BY DEFAULT AS IDENTITY` |
| `Boolean` | `bool` | the type | `bool` | `boolean` |
| `Char` | `String` | `max_length = n` | `varchar(n)` | `varchar(n)` |
| `Text` | `String` | no `max_length`, or `text` | `text` | `text` |
| `SmallInteger` | `i8`, `i16` | the type | `smallint` | `smallint` |
| `Integer` | `i32` | the type | `integer` | `integer` |
| `BigInteger` | `i64`, `isize` | the type | `bigint` | `bigint` |
| `PositiveSmallInteger` | `u8`, `u16` | the type | `smallint` + `CHECK (col >= 0)` | `smallint` + `CHECK (col >= 0)` |
| `PositiveInteger` | `u32` | the type | `integer` + `CHECK (col >= 0)` | `integer` + `CHECK (col >= 0)` |
| `PositiveBigInteger` | `u64`, `usize` | the type | `bigint` + `CHECK (col >= 0)` | `bigint` + `CHECK (col >= 0)` |
| `Float` | `f32`, `f64` | the type | `real` | `double precision` |
| `Decimal` | `rust_decimal::Decimal` | `max_digits`, `decimal_places` | `decimal` | `numeric(max_digits, decimal_places)`, default `numeric(10, 2)` |
| `Date` | `NaiveDate` | the type | `date` | `date` |
| `Time` | `NaiveTime` | the type | `time` | `time` |
| `DateTime` | `DateTime<Utc>` (`use_tz` true) or `NaiveDateTime` (`use_tz` false) | the type | `datetime` | `timestamp with time zone` |
| `Duration` | `chrono::TimeDelta` | the type | `bigint` (microseconds) | `interval` |
| `Email` | `String` | `email` | `varchar(254)` | `varchar(254)` |
| `Url` | `String` | `url` | `varchar(200)` | `varchar(200)` |
| `Slug` | `String` | `slug` | `varchar(50)` | `varchar(50)` |
| `Uuid` | `uuid::Uuid` | the type | `char(32)` | `uuid` |
| `Binary` | `Vec<u8>` | the type, or `binary` | `blob` | `bytea` |
| `Json` | `serde_json::Value` | the type, or `json` | `text` + `CHECK (JSON_VALID(col) OR col IS NULL)` | `jsonb` |
| `GenericIpAddress` | `String` | `ip` | `char(39)` | `inet` |
| `File` | `String` | `file` | `varchar(100)` | `varchar(100)` |
| `Image` | `String` | `image` | `varchar(100)` | `varchar(100)` |
| `ForeignKey` | `ForeignKey<T>` | the type | `<field>_id`, type of the target key, `REFERENCES` | the same, with a deferred `FOREIGN KEY` constraint |
| `OneToOne` | `OneToOne<T>` | the type | as `ForeignKey` plus `UNIQUE` | as `ForeignKey` plus `UNIQUE` |
| `ManyToMany` | `ManyToMany<T>` | the type | no column; link table | no column; link table |

Notes on the table:

- `max_length` on `email`, `url`, `slug`, `file` and `image` replaces the default length. `Char` with `max_length`
  unset (only possible for a hand-built field) is `varchar(255)`.
- A flag (`text`, `email`, `url`, `slug`, `json`, `binary`, `ip`, `file`, `image`) wins over the type. Without a flag
  a `String` is `Char` when `max_length` is given and `Text` otherwise.
- `Vec<u8>` is recognised by the name `Vec`; any `Vec<...>` becomes `Binary`.
- `serde_json::Value` is recognised by the last segment `Value`.
- `TimeDelta` must be spelled with that name.
- The `DateTime` kind reads back as `DateTime<Utc>` when the `use_tz` setting is true and as `NaiveDateTime` when
  it is false; the Rust type has to match the setting.
- Foreign key columns copy the type of the target's key: `auto` gives `integer`, `big_auto` gives `bigint`, a `String`
  key gives its `varchar`.
- Choices, validators, column comments and database-level defaults exist in the field metadata but cannot be set
  through the derive.

## Column types

What the schema editor writes for a column, on both backends:

| Aspect | SQL |
|---|---|
| Nullability | `NULL` when the field is `null` or `Option<T>`, otherwise `NOT NULL`. |
| Primary key | `PRIMARY KEY`; on SQLite an auto key also gets `AUTOINCREMENT`. |
| `unique` | `UNIQUE` on the column. |
| `db_index` (not unique, not primary key) | `CREATE INDEX` named `<table>_<columns>_<hash>`. Text-like columns on PostgreSQL also get a second index with `varchar_pattern_ops` (suffix `_like`) so that prefix searches can use it. |
| Foreign key | SQLite: inline `REFERENCES "table" ("col") DEFERRABLE INITIALLY DEFERRED`. PostgreSQL: a later `ALTER TABLE ... ADD CONSTRAINT ... FOREIGN KEY ... DEFERRABLE INITIALLY DEFERRED`. No `ON DELETE` clause: deletes are cascaded by the program. A relation with `db_constraint` false (hand-built fields) gets no constraint. |
| Foreign key index | A foreign key field is indexed by default; a one-to-one field is unique instead. |
| `unique_together` | SQLite: `CREATE UNIQUE INDEX ..._uniq`. PostgreSQL: `ALTER TABLE ... ADD CONSTRAINT ..._uniq UNIQUE (...)`. |
| Many-to-many | A link table `<model table>_<field>` with `id`, `<model>_id`, `<target>_id` (or `from_<model>_id`, `to_<model>_id` for a self relation) and a unique pair. |
| `default` | Not part of `CREATE TABLE`. Used as `DEFAULT` when a non-null column is added to an existing table. |

SQLite stores several kinds as text or integers; see
[How SQLite stores values](../topics/db/databases.md#how-sqlite-stores-values).

## Field attributes

Written inside `#[field(...)]`. A bare word is a flag; `name = value` takes a literal. An unknown attribute is a
compile error (`unknown field option`).

### Flags

| Flag | Effect |
|---|---|
| `primary_key` | The field is the primary key. Exactly one is required. |
| `auto` | 32-bit auto-incrementing key; implies `primary_key`. |
| `big_auto` | 64-bit auto-incrementing key; implies `primary_key`. |
| `null` | The column accepts `NULL`. `Option<T>` already implies it. |
| `blank` | Forms and serializers may leave the field empty. No effect on the column. |
| `unique` | `UNIQUE` constraint. |
| `db_index` | Create an index on the column. |
| `auto_now` | Set to the current time on every save; also marks the field not editable and blank. |
| `auto_now_add` | Set to the current time when the row is first inserted; also not editable and blank. |
| `text`, `email`, `url`, `slug`, `json`, `binary`, `ip`, `file`, `image` | Select the field kind (see the table above). |

`auto_now` and `auto_now_add` work on `DateTime<Utc>`, `NaiveDateTime` and `NaiveDate` fields and their `Option<...>`
forms; the value is written to the struct before the row is saved.

### Valued attributes

| Attribute | Value | Applies to | Effect |
|---|---|---|---|
| `max_length` | integer | string kinds | Column length. Also makes a plain `String` a `Char`. |
| `max_digits` | integer | `Decimal` | Total digits (PostgreSQL `numeric` precision). |
| `decimal_places` | integer | `Decimal` | Digits after the point. SQLite values are rounded to this many places. |
| `default` | any expression convertible to a database value | any | Default for added columns, form initial values and `on_delete = "set_default"`. Not applied to the Rust struct. |
| `db_column` | `"name"` | any column | Column name. Default: the field name, or `<field>_id` for a foreign key. |
| `verbose_name` | `"text"` | any | Label for forms and the admin. Default: the field name with underscores as spaces. |
| `help_text` | `"text"` | any | Help text for forms. |
| `editable` | `false` | any | Leave the field out of model forms. |
| `upload_to` | `"dir"` | `file`, `image` | Directory under the storage root for uploads. |
| `on_delete` | `"cascade"` (default), `"protect"`, `"restrict"`, `"set_null"`, `"set_default"`, `"do_nothing"` | relations | What deleting the target does. Another string means `"cascade"`. |
| `related_name` | `"name"` | relations | Name of the reverse relation (accessor and lookups); `"name+"` hides it. |
| `related_query_name` | `"name"` | relations | Name of the reverse relation in lookups only. |
| `to_field` | `"field"` | `ForeignKey`, `OneToOne` | Join on this target field instead of the primary key. |
| `through` | `"app.Model"` | `ManyToMany` | Explicit link model. |

`max_length`, `max_digits` and `decimal_places` must be integer literals. `default` takes any expression:
`default = 0`, `default = false`, `default = "draft"`.

### Field markers

| Marker | Effect |
|---|---|
| `#[model(skip)]` | The field is not a column. It is filled with `Default::default()` on load and ignored on save. |
| `#[model(state)]` | A field of type `ModelState`: bookkeeping slot, not a column, reset on load. A field of that type is recognised without the marker. |

### Primary keys

A model needs exactly one primary key field, or the derive fails with `a model needs a primary key field`.
`Option<i64>` means "not saved yet" when `None`; a plain integer key treats `0` as unsaved; a `String` or `Uuid` key is
assigned by you. `pk` is accepted as a field name in lookups and ordering.

Written in `#[model(...)]` on the struct. Details in [Models](../topics/db/models.md#model-options).

| Option | Value | Default |
|---|---|---|
| `app_label` | `"polls"` | module path: the parent of a `models` module, else the crate name |
| `db_table` | `"legacy_questions"` | `<app_label>_<lowercased struct name>` |
| `ordering` | `["-pub_date", "id"]` or `"id"` | none |
| `verbose_name`, `verbose_name_plural` | `"poll question"` | words of the struct name; plural adds `s` |

| `get_latest_by` | `"pub_date"` or a list | none |
| `managed` | `false` | `true` |
| `crate` | `"rango::db"` | `::rango::db` |

## Values and Rust types

Rows and query parameters travel as `rango::db::Value`. `ToValue` turns a Rust value into one (for filters and
`update`), `FromValue` reads one back (for model fields and `values_flat`).

| `Value` variant | Rust types |
|---|---|
| `Null` | `None` of any `Option<T>` |
| `Bool(bool)` | `bool` |
| `Int(i64)` | `i8` ... `i64`, `u8` ... `u64`, `isize`, `usize` |
| `Float(f64)` | `f32`, `f64` |
| `Decimal(Decimal)` | `Decimal` |
| `Str(String)` | `String`, `&str` |
| `Bytes(Vec<u8>)` | `Vec<u8>` |
| `Date(NaiveDate)` | `NaiveDate` |
| `Time(NaiveTime)` | `NaiveTime` |
| `DateTime(DateTime<Utc>)` | `DateTime<Utc>` |
| `NaiveDateTime(NaiveDateTime)` | `NaiveDateTime` |
| `Duration(TimeDelta)` | `TimeDelta` |
| `Uuid(Uuid)` | `Uuid` |
| `Json(serde_json::Value)` | `serde_json::Value` |

Reading is forgiving in a few places: an integer field accepts a `Value::Float` with no fraction, a `Bool`, a
`Decimal` or a numeric `Str`; a `String` field accepts an `Int` or a `Uuid`; a float accepts an `Int`. Anything else
fails with `cannot convert ... to <type>`. An out-of-range integer fails the same way. `Value` has `is_null()`,
`as_str()` and `as_i64()` (which also converts `Bool`).

## Building fields by hand

Hand-written migrations and tests describe fields with the `Field` builder in `rango::db::models` (the same calls
`makemigrations` writes).

Constructors:

| Constructor | Result |
|---|---|
| `Field::new(name, FieldType::X)` | A field of any kind, with no options. |
| `Field::auto(name)`, `Field::big_auto(name)` | Primary-key auto fields. |
| `Field::char(name, max_length)`, `Field::text(name)` | Text fields. |
| `Field::integer(name)`, `Field::big_integer(name)`, `Field::boolean(name)`, `Field::float(name)` | |
| `Field::decimal(name, max_digits, decimal_places)` | |
| `Field::date(name)`, `Field::datetime(name)`, `Field::time(name)`, `Field::uuid(name)`, `Field::json(name)` | |
| `Field::slug(name, max_length)` | A slug field that is also indexed. |
| `Field::email(name)` | An email field with length 254. |
| `Field::foreign_key(name, "app.Model", on_delete)` | Indexed foreign key. |
| `Field::one_to_one(name, "app.Model", on_delete)` | Unique foreign key. |
| `Field::many_to_many(name, "app.Model")` | Many-to-many field. |

Modifiers (each returns the field): `.null()`, `.blank()`, `.unique()`, `.db_index()`, `.primary_key()`,
`.default(value)`, `.default_fn(fn() -> Value)`, `.auto_now()`, `.auto_now_add()`, `.db_column(name)`,
`.verbose_name(text)`, `.help_text(text)`, `.upload_to(dir)`, `.choices(vec![(Value, label)])`,
`.related_name(name)`, `.related_query_name(name)`, `.to_field(name)`, `.through(label)`, `.db_constraint(bool)`, and
`.with(|f| { ... })`, which gives mutable access to every public field of `Field`.

Public fields of `Field`: `name`, `ty`, `db_column`, `null`, `blank`, `unique`, `db_index`, `primary_key`,
`editable`, `default` (`Option<Default_>`: `Default_::Value(v)` or `Default_::Callable(fn)`), `max_length`,
`max_digits`, `decimal_places`, `auto_now`, `auto_now_add`, `choices`, `verbose_name`, `help_text`, `upload_to`,
`db_comment`, `db_default`, `unique_for_date`, `rel` (`Option<Relation>`), `validators`. The schema editor reads
the type, nullability, uniqueness, indexing, length, precision, `db_column`, `default` (a `Value` default) and
`rel`; `choices`, `validators`, `db_comment`, `db_default` (apart from allowing a column to be added without a
`default`) and `unique_for_date` are carried but not acted on.

`Relation` has `to` (a label or `"self"`), `on_delete`, `related_name`, `related_query_name`, `to_field`, `through`
and `db_constraint`; `symmetrical`, `parent_link` and `limit_choices_to` exist but are not used.

`OnDelete` is `Cascade`, `Protect`, `Restrict`, `SetNull`, `SetDefault`, `SetValue(Value)` or `DoNothing`.
`SetValue` writes the given value into the referencing rows; it can only be built by hand, and `makemigrations` writes
it back as `SetNull`.

`ModelMeta` (the model's metadata, `Model::meta()`) has `app_label`, `object_name`, `db_table`, `fields`,
`ordering`, `unique_together`, `indexes` (`Index { name, fields, condition, include }`), `constraints`
(`Constraint::Unique` / `Constraint::Check`), `verbose_name`, `verbose_name_plural`, `managed`, `get_latest_by`,
`default_related_name`, `str_field` and a few slots that are not used yet (`abstract_`, `proxy_for`, `parent`,
`select_on_save`, `permissions`, `index_together`, `db_table_comment`). Build one with
`ModelMeta::new(app, name)`, `.field(f)`, `.db_table(t)`, `.ordering(&[...])`, `.unique_together(&[...])` and
`.verbose_name(single, plural)`. `label()` is `app_label.ObjectName`; `get_field(name)` accepts a field name or its
column attribute name (`question_id`); `pk()` returns the primary key field; `concrete_fields()` skips many-to-many
fields.

## Not supported yet

- Choices, validators, `unique_for_date`, column comments and database defaults through the derive.
- Generated columns, file-path fields, array and range fields.
- Multi-column indexes, check constraints and conditional constraints on a model.
- Abstract, proxy and multi-table inheritance.
- Image dimension fields.
